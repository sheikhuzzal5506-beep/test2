# Smart Escape

Smart Escape is a responsive, browser-only landing page for an emergency route planning concept. It uses plain HTML, CSS, JavaScript, and original SVG artwork. No install or build step is required.

## Run locally

Open `index.html` in a browser, or use the **Live Server** extension in VS Code to serve the project folder.

## Files

- `index.html` — page content and accessible structure
- `style.css` — responsive visual design and animations
- `script.js` — mobile navigation, scroll reveals, and route demo interaction
- `assets/` — original SVG illustrations
